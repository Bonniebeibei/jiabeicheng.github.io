这篇文章的核心观点是：如果把细胞群体内部的异质性建模出来，并用跨数据集学习的细胞状态表征吸收技术差异，就能把已知扰动的效应迁移到新的细胞情境中，并进一步支持差异表达分析、表型预测和 in silico 实验。

作者提出 State，由两个模块组成：State Embedding model（SE）负责学习跨数据集的细胞状态表示，State Transition model（ST）负责预测细胞群体在给定扰动下如何转变。

全文的主线可以概括为：

**群体异质性建模 → 少样本情境迁移 → 新情境 zero-shot 预测 → 细胞类型特异反应 → in silico 扰动实验**

---

## Fig. 1：为什么 State 要以细胞集合为单位建模

![State Figure 1](https://raw.githubusercontent.com/Bunnybeibei/jiabeicheng.github.io/master/images/State-fig1.png)

Fig. 1 的论证目标是：**单细胞扰动预测的关键障碍不是简单的表达重建，而是如何从细胞群体异质性和技术噪声中分离真正的扰动效应；State 的 set-based transformer 正是为了解决这个问题。**

**Fig. 1a** 定义问题：扰动信号往往小于细胞群体内部的异质性。逐细胞预测容易被个体差异和技术噪声干扰，而直接预测群体平均值又会抹去真实的亚群和状态差异。

**Fig. 1b** 给出 State 的整体结构：

- **State Embedding model（SE）**：用 1.67 亿个观测性细胞预训练，学习跨数据集、对技术噪声更稳健的细胞表示；
- **State Transition model（ST）**：输入一组未扰动细胞和扰动标签，输出扰动后的细胞群体。

**Fig. 1c** 具体说明 ST 如何工作。它的设计假设是：**细胞对扰动的响应取决于其原本所处的状态，因此模型必须保留群体内部差异，并显式建模细胞之间的关系。**

**Fig. 1d** 是支撑架构选择的关键证据。随着输入集合从单个细胞扩展到数百个细胞，验证损失明显下降，并在约 768 个细胞时达到最佳表现。这个结果支持的不是泛泛的“模型越大越好”，而是一个更具体的结论：扰动预测需要同时保留单细胞信息，并利用细胞集合的分布和内部关系。

因此，Fig. 1 的完整逻辑是：

**群体异质性掩盖扰动信号 → 逐细胞预测与群体平均都不充分 → 用 set transformer 建模细胞分布 → set size 与 self-attention 的消融支持这一设计。**

## Fig. 2：目标情境存在少量扰动数据时的泛化能力

![State Figure 2](https://raw.githubusercontent.com/Bunnybeibei/jiabeicheng.github.io/master/images/State-fig2.png)

Fig. 2 建立 State 的基础性能结论：**当目标细胞情境只测过一小部分扰动时，State 能把其他情境中学到的扰动规律迁移过来，并在多种生物学指标上优于现有方法。**

**Fig. 2a** 定义泛化任务，并引入两个关键朴素基线：

1. **PerturbMean**：使用同一扰动在其他细胞情境中的平均效应；
2. **ContextMean**：使用目标情境中不同扰动后的平均表达状态。

这两个基线分别检验模型是否只是记住“某个扰动通常产生什么效果”，或者“某个细胞情境通常如何响应”。

**Fig. 2b** 将证据扩展到三类扰动数据：

- **Tahoe-100M**：药物扰动，覆盖 50 个细胞系和 1,138 个条件；
- **Parse-PBMC**：细胞因子与信号扰动，覆盖 18 种细胞类型和 90 个扰动；
- **Replogle-Nadig**：遗传扰动，覆盖 4 个细胞系和 2,024 个扰动。

作者同时比较 linear model、GEARS、scVI、CPA 和 scGPT 等方法。这个 panel 的作用，是说明性能结论并非来自单一数据集或单一扰动模态。

**Fig. 2c** 定义 Cell-Eval。作者认为，仅看表达重建相关性不足以评价 perturbation model，因此将评价指标分成三个层次：

1. **表达层面**：能否区分不同扰动，以及整体表达变化是否相关，包括 perturbation discrimination score 和 Pearson correlation；
2. **差异表达层面**：能否找回正确的 DEG 及其显著性和变化幅度，包括 AUPRC、fold change 和 DEG overlap；
3. **效应大小层面**：能否判断哪些扰动强、哪些扰动弱。

**Fig. 2d–j** 从上述不同指标和数据集比较 State 与基线，证明优势覆盖药物、信号和遗传扰动，而不只体现为单一的表达相关性提升。

**Fig. 2k** 将扰动效应大小展开检查。混淆矩阵显示，药物扰动的强效应通常沿对角线分布；遗传扰动的信号更弱、更分散，但 State 仍能恢复总体的强弱排序。

因此，Fig. 2 的价值不仅是给出一个综合 benchmark，还在于用 Cell-Eval 把“预测准确”拆成表达重建、差异表达恢复和效应大小排序三个可解释层次。

## Fig. 3：State Embedding 支持新细胞情境的 zero-shot 预测

![State Figure 3](https://raw.githubusercontent.com/Bunnybeibei/jiabeicheng.github.io/master/images/State-fig3.png)

Fig. 3 的核心问题是：State Embedding（SE）能否帮助模型在**目标细胞情境完全没有扰动数据**时进行 zero-shot 预测？

### 1. SE embedding 是否保留扰动信息

**Fig. 3a** 展示 ST+SE 的预测流程：SE 将 control cells 编码为 embedding，ST 预测扰动后的 embedding，decoder 再将其还原为基因表达。

**Fig. 3b** 定义两类评估：

- **intrinsic evaluation**：真实扰动细胞在 embedding 空间中是否可区分；
- **extrinsic evaluation**：ST 预测出的扰动 embedding 是否仍然可区分。

**Fig. 3c** 将 SE 与 scFoundation、scGPT、UCE 和 Transcriptformer 比较。SE 在真实及预测 embedding 的扰动可分性上总体更好，部分情况下甚至优于原始表达矩阵。这说明 SE 不只是在压缩表达数据，而是在保留并强化与扰动有关的信号。

### 2. Zero-shot 预测新细胞情境

**Fig. 3d** 定义严格的 zero-shot 设置：模型可以看到目标情境的 control cells，但该情境中的任何 perturbation data 都不能参与训练。

作者比较 ST+SE、直接使用 highly variable genes 的 ST+HVG，以及 PerturbMean、ContextMean 等基线。ST+SE 在大多数 Cell-Eval 指标上优于 ST+HVG，说明统一 embedding 能帮助模型把其他情境中的扰动规律迁移到新的细胞类型或细胞系。

### 3. 通过模拟响应识别药物作用机制

**Fig. 3e** 在未见过药物扰动的 A549 细胞中模拟 1,137 种药物，并比较：

\[
\text{模拟药物效应} \quad \text{vs.} \quad \text{真实基因敲低效应}
\]

对于 MEK 抑制剂 trametinib，与其最相似的 genetic perturbations 包括 PTPN11、RAF1 和 SHOC2 等 MEK 通路相关基因。这个任务检验的是：State 的预测 embedding 是否保存了足以识别 drug mechanism of action 的调控关系。

### 4. 跨数据集、实验平台和扰动模态迁移

**Fig. 3f** 先在大规模 Tahoe-100M 药物数据上预训练 ST+SE，再在新的 query dataset 中利用部分细胞情境微调，同时完全留出一个目标情境用于测试。

**Fig. 3g** 在 5 个数据集、34 个细胞情境中，评价模型能否正确排序不同扰动的整体效应大小。ST+SE 通常优于 ST+HVG 和 PerturbMean，说明预训练获得的细胞状态与扰动规律能够迁移到不同数据集、实验平台，以及药物、细胞因子和遗传扰动等不同模态。

因此，Fig. 3 的论证逐级推进：

**SE embedding 保留扰动信息 → SE 改善新情境的 zero-shot 预测 → 预测空间保留机制相关关系 → 预训练能力跨数据集和扰动模态迁移。**

## Fig. 4：State 学到了细胞情境特异的扰动反应

![State Figure 4](https://raw.githubusercontent.com/Bunnybeibei/jiabeicheng.github.io/master/images/State-fig4.png)

Fig. 4 进一步排除一种简单解释：State 是否只是输出某种扰动的平均反应？作者从基因、细胞状态、药物关系和功能表型四个层次，检验模型是否真正学到了**细胞类型或细胞系特异的扰动反应**。

### 1. 细胞系特异的差异表达

作者在 Tahoe-100M 中留出 5 个细胞系，仅使用其 control cells 预测药物处理后的表达变化。

- **Fig. 4a** 定义留出细胞系的实验设置；
- **Fig. 4b** 检验能否找回真实 DEG；
- **Fig. 4c** 检验能否预测 DEG 的 fold change；
- **Fig. 4d** 检验能否预测 DEG 显著性；
- **Fig. 4e** 检验表达变化的方向和幅度；
- **Fig. 4f** 检验同一药物在不同细胞系中能否恢复不同的 top DEGs。

Trametinib–C32 被用作代表案例。State 明显优于 PerturbMean 和 ContextMean，说明它既不是输出“该药物的平均反应”，也不是输出“该细胞系的平均状态”。

### 2. 保留细胞周期异质性

**Fig. 4g** 根据预测表达谱计算 G2/M 和 S-phase scores，并与真实扰动后细胞比较。相对于 PerturbMean，State 对 G2/M 和 S phase 的误差分别下降约 36.7% 和 45.6%。这说明预测没有把群体过度平均，仍然保留了细胞周期状态差异。

### 3. 恢复药物之间的相似性结构

**Fig. 4h** 对每个药物—浓度组合，用其在不同细胞系中的表达变化构成 fingerprint，再计算药物之间的相似性。State 预测得到的药物聚类与真实实验高度一致，ARI 大于 0.7；PerturbMean 的 ARI 则低于 0.1。

这说明 State 不仅预测单个样本，还能恢复哪些药物具有相似的跨细胞系响应模式。

### 4. 从表达变化预测细胞存活率

**Fig. 4i** 将 State 预测的扰动后表达谱输入回归模型，用于预测实际 cell viability。预测与真实存活率变化的相关性约为：State 0.52、PerturbMean 0.31、ContextMean 0.20。

因此，Fig. 4 的证据层次是：

**细胞系特异的基因响应 → 细胞周期状态 → 药物关系结构 → 细胞存活表型。**

这说明 State 的预测不仅在表达空间中接近真实数据，还能传递到更高层次的生物学分析与功能表型。

## Fig. 5：从预测实验结果走向虚拟实验

![State Figure 5](https://raw.githubusercontent.com/Bunnybeibei/jiabeicheng.github.io/master/images/State-fig5.png)

Fig. 5 是全文在应用层面的收束：**State 的预测能否支持研究者通常依靠扰动筛选完成的任务，并探索没有被直接测量的组合与扰动模态？**

### 1. 预测通路和基因程序变化

**Fig. 5a–c** 在留出的 RPE1 细胞中，比较各种扰动对细胞周期、翻译和线粒体功能等 gene programs 的影响。State 的预测与真实实验高度一致，说明模型能够恢复协调的通路级响应，而不只是若干单基因变化。

### 2. 根据目标状态反推扰动

**Fig. 5d** 给定一个希望获得的扰动后转录组状态，让模型从所有候选扰动中找出最可能产生该状态的扰动。State 的 top-k 命中率高于 PerturbMean 和 ContextMean，说明它可以用于初步的扰动筛选和实验设计。

### 3. 预测药物组合的非加和效应

**Fig. 5e–f** 先模拟药物 A 处理后的细胞状态，再以该状态为起点模拟药物 B。作者将预测的组合效应与两个单药效应之和比较，从而估计协同或拮抗作用；预测结果与 DrugComb 中的 Bliss、ZIP 等实验指标显著相关。

### 4. 从药物扰动外推到遗传扰动

**Fig. 5g–i** 用已学到的药物 embedding 组合近似模型从未训练过的 genetic perturbation，再模拟这些基因扰动在不同细胞系中的效果。具体过程是：

1. 获取某个基因敲低产生的平均表达变化 \(g\)；
2. 从药物扰动库中寻找一小组药物，使其表达效应的加权组合最接近 \(g\)；
3. 用相同权重组合这些药物的 embedding；
4. 将组合 embedding 作为该 genetic perturbation 的代理表示；
5. 输入 State，预测该基因敲低在不同细胞系中的效应。

预测结果能够恢复蛋白酶体、核糖体、细胞周期和 KRAS-G12C 等生物学结构，并与 DepMap 的 CRISPR essentiality 数据显著相关。

因此，Fig. 5 的应用链条是：

**复现实验分析 → 根据目标状态反向选择扰动 → 模拟药物组合 → 跨扰动模态构造未见扰动。**

## 结果组织方式总结

这篇文章的实验并不是重复证明“hold-out prediction 更准确”，而是沿两条轴展开：

1. **泛化难度**：目标情境有少量扰动数据（Fig. 2）→ 目标情境完全没有扰动数据（Fig. 3）→ 跨数据集、实验平台和扰动模态迁移；
2. **生物学读出层次**：表达值与扰动区分 → DEG、fold change 与效应大小 → gene programs 与细胞周期 → 药物关系和作用机制 → cell viability 与组合效应。

这样的组织方式把“虚拟细胞具有广泛潜力”拆成了一组具体、可评价的任务，也让每个实验回答不同的问题。

## Takeaway

虽然这篇文章的落脚不是明显的生物发现，它值得学习的地方是作者想了很多下游任务：相比于说 State 在虚拟细胞中有巨大的潜力，不如像作者一样具体地列出这些潜力是什么：比如同样是 hold-out 预测，可以分为目标情境有少量扰动数据的预测（Fig. 2）和 zero-shot 预测（Fig. 3d）；可以分为化学扰动、基因扰动、信号扰动（Fig. 2b、2d–k）；分子读出可以分为具体的表达预测值（Fig. 2e）、基因通路（Fig. 5a–c）、细胞系特异的差异表达（Fig. 4b–f）。然后扰动应用又可以分为：用目标状态从生成的 candidate 状态中搜索对应扰动（Fig. 5d），跨扰动方式构造（用药物扰动表示的组合近似遗传扰动，Fig. 5g–i），预测药物组合的非加和效应（Fig. 5e–f）。此外，模型的预测结果也可以用于下游任务，比如计算细胞周期评分（Fig. 4g）、预测细胞存活率（Fig. 4i）；也可以做生物学关系和机制分析，比如恢复药物之间的相似度结构（Fig. 4h）、通过药物—遗传响应匹配推断药物作用机制（Fig. 3e）。
